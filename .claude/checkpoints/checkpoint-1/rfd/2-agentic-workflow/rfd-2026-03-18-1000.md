# RFD-2: AgenticWorkflow + DataFrame Orchestration

**Status:** Complete
**Date:** 2026-03-18
**Depends on:** RFD-1 (Core AgenticReviewer)

## Goal

Implement `AgenticWorkflow` — the multi-round pipeline orchestrator that processes DataFrames through sequences of `AgenticReviewer` instances. Achieves v1 feature parity for workflow orchestration using the new agentic reviewer infrastructure.

## Design Decisions

### v1 Compatibility (verified against v1 tutorials)
- Same schema format: `round`, `reviewers`, `text_inputs`, `filter`
- Same column naming: `round-{ROUND_ID}_{REVIEWER_NAME}_{KEYWORD}`
- Same `_output` column stores dict (not string) — enables v1 filter pattern: `row["round-A_Agent1_output"]["score"]`
- Same `reviewer_costs` dict with tuple keys `(round_id, reviewer_name)` matching v1
- Same `get_total_cost()` API
- Same input flexibility: DataFrame, dict, CSV, XLSX
- Same `_format_text_input()` pattern: `=== col ===\nvalue` blocks
- Same `Review Task ID: {round}-{idx}` prefix in text inputs
- Same `verbose` parameter using `print()` for user-visible output
- Same `__call__` interface for running workflows

### v2 Enhancements
- `working_dir` parameter (passed through to reviewers for future state persistence)
- Schema validation at init time (missing keys, duplicate round IDs, type checks)
- Uses `AgenticReviewer.review_items()` for concurrent batch processing with Pydantic AI
- Error handling via `_error` field from reviewer (no JSON parsing needed — Pydantic AI handles structured output)
- Cross-round column references (round B can use round A output columns as text inputs)

### What's Deferred to Later RFDs
- Checkpoint/resume with `resume: bool` parameter (RFD-7)
- Flagged item revisiting with `revisit_flagged: bool` parameter (RFD-5)
- DataFrame snapshots after rounds (RFD-7)
- Image inputs (AgenticReviewer doesn't support images yet)
- RIS file direct loading (users convert to DataFrame first)

## v1 Compatibility Verification

- Schema format matches v1 `ReviewWorkflow` exactly
- Column naming convention `round-{ID}_{name}_{field}` matches
