# RFD-7: Checkpoint/Resume System

**Date:** 2026-03-18
**Status:** COMPLETE

## Goal

Implement atomic per-item checkpointing and crash-resume for `AgenticWorkflow`. After each item review, results are saved to disk. On resume, completed items are skipped, memory/flag stores are reloaded, and the workflow continues from the exact interruption point. Also add per-item structured action logging (JSONL) and DataFrame snapshots after each round.

## Architecture

### RunState (`checkpoint/state.py`)
- Pydantic BaseModel for JSON serialization
- Fields: created_at, updated_at, status (running/completed/paused/failed), schema_hash, current_round_index, current_reviewer_index, completed_items (Dict[str, List[str]]), total_cost
- `mark_item_completed()` / `is_item_completed()` / `get_completed_items()` helpers
- `compute_schema_hash()` — deterministic SHA-256 hash of round IDs, reviewer names, output types, max_iterations, and text_inputs

### CheckpointManager (`checkpoint/manager.py`)
- `initialize(schema)` — create fresh RunState for new run
- `can_resume()` / `load_for_resume(schema)` — detect and load prior run, warn if schema hash differs
- `save_item_result(round_id, reviewer_name, item_id, result, cost)` — atomic write-to-temp-then-rename, updates RunState
- `load_item_result()` — load saved result
- `get_completed_items()` — from RunState, with disk-scan fallback
- `save_dataframe_snapshot(df, round_id)` / `save_final_dataframe(df)` — parquet snapshots
- `mark_completed()` / `mark_failed()` — status updates

### ActionLogger (`logging/action_log.py`)
- Per-item JSONL files at `working_dir/round_{ID}/agent_{NAME}/logs/item_{N}.jsonl`
- `log(item_id, action_type, details)` — append entry with timestamp
- `read_log(item_id)` / `has_log(item_id)` — read back

### Workflow Integration
- `AgenticWorkflow.resume: bool = False` — new param
- On `run()`: creates CheckpointManager if working_dir set
- Resume flow: load prior state, warn on schema change, skip completed items, reload saved results into DataFrame
- Per-item: reviewer calls `checkpoint_manager.save_item_result()` after each review
- Per-round: saves parquet snapshot via `save_dataframe_snapshot()`
- On completion: saves final.parquet, marks state completed
- On failure: marks state failed (in try/except)

### Storage Layout
```
working_dir/
├── run_metadata.json
├── round_A/
│   └── agent_Reviewer/
│       ├── results/item_A-0.json, item_A-1.json, ...
│       ├── logs/item_A-0.jsonl, item_A-1.jsonl, ...
│       ├── memory/
│       └── flags/
└── output/
    ├── after_round_A.parquet
    └── final.parquet
```

## Deviations from Plan

- Added `pyarrow` dependency for parquet support (was not in pyproject.toml optional deps)
- ActionLogger is synchronous (no async needed for append-only JSONL writes)
- Checkpoint save happens in `review_item()` rather than in workflow loop, keeping the per-item atomicity cleaner
